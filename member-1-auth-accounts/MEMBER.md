# FINDMYITEM — Member 1: Auth & Accounts

This folder contains **your part** of the FINDMYITEM team project.

## Your responsibility
User authentication and accounts: the Django `accounts` app (models, serializers, views, URLs, admin, tests, migrations) plus the React auth screens — Login, Register, the AuthContext, and the ProtectedRoute guard.

The files are kept in their real project paths (`backend/...`, `frontend/...`)
so it's clear where they belong in the full app.

> Note: this folder is only your slice, so it will **not run on its own** — it
> plugs into the full app the team assembles. Your job is to own, commit, and
> push these files to your own GitHub account.

## Push this to YOUR GitHub account
1. Create a new **empty** repo on GitHub (e.g. `findmyitem-part-1`) — no README.
2. In this folder, run:
   ```bash
   git init -b main
   git config user.name  "Your Name"
   git config user.email "your-github-email@example.com"
   git add .
   git commit -m "Member 1: Auth & Accounts"
   git remote add origin https://github.com/<your-username>/findmyitem-part-1.git
   git push -u origin main
   ```
That's it — your work now lives under your own account.
